A simple mod menu for Among Us! This is currently in alpha version so it might be buggy.

Installation:

  Step 1:
    You have to download BepInEx Unity (IL2CPP) for Windows (x86) games: https://builds.bepinex.dev/projects/bepinex_be
    Extract the contents of the .zip file into the Among Us folder.
    
  Step 2:
    After that you have to download Reactor: https://docs.reactor.gg/
    Put the Reactor.dll fle into C:\Program Files (x86)\Steam\steamapps\common\Among Us\BepInEx\plugins (or if you installed it somewhere else, but make sure that the .dll file is in the plugins folder)

  Step 3:
    Put the ZMenu.dll into the plugins folder!

Issues that may occur:
  If you can`t see the plugins folder you have to run among us(after you extracted the contents).

  THIS IS FOR STEAM EDITION ONLY IT`S NOT TESTED WITH OTHERS!
